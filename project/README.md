# PotjieBook project pack

Files to set PotjieBook up as a project. See `HANDOVER.md` section 6 for the steps.

**Claude Project:** paste `PROJECT_INSTRUCTIONS.md` into the project instructions, and add `HANDOVER.md`, `RECIPES.md`, `COOKING_PREFERENCES.md` and `APP_REFERENCE.md` as project files.

**Claude Code:** choose this repository. `CLAUDE.md` at the top loads automatically.
